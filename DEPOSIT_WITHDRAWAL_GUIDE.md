# TON Casino - Руководство по Депозитам и Выводам

## 🔐 Как Работает Система Депозитов и Выводов

### Архитектура

Приложение использует **TON Connect** для интеграции с блокчейном TON. Это не требует создания смарт-контрактов - вместо этого используется стандартный протокол TON Connect для отправки транзакций напрямую между кошельками.

### Принцип Работы

#### 📥 **Депозиты (Пополнение)**

1. **Пользователь нажимает "Deposit"** в своем профиле
2. **Указывает сумму** для пополнения (например, 1 TON)
3. **TON Connect создает транзакцию** отправки TON с кошелька пользователя на кошелек казино
4. **Пользователь подтверждает** в своем TON кошельке (Tonkeeper, MyTonWallet и т.д.)
5. **Баланс в приложении обновляется** автоматически после подтверждения

**Технические детали:**
```typescript
const transaction = {
  validUntil: Math.floor(Date.now() / 1000) + 300, // 5 минут на подтверждение
  messages: [
    {
      address: casinoWallet, // Адрес кошелька казино
      amount: String(Math.floor(depositAmount * 1000000000)), // Сумма в nanotons
    },
  ],
};

const result = await tonConnectUI.sendTransaction(transaction);
```

#### 📤 **Выводы (Вывод средств)**

1. **Пользователь нажимает "Withdraw"**
2. **Указывает сумму** для вывода
3. **Система создает транзакцию** отправки TON с кошелька казино на кошелек пользователя
4. **Пользователь получает TON** на свой подключенный кошелек

**Важно:** В текущей реализации выводы работают как **обратная транзакция** - пользователь отправляет запрос, и баланс в приложении уменьшается. Для полноценной работы требуется бэкенд-сервис, который будет автоматически отправлять TON пользователям.

### Лимиты

- **Лимит на одну транзакцию вывода:** 1,500 TON
- **Дневной лимит вывода:** 7,500 TON
- **Лимиты депозита:** отсутствуют (ограничены только балансом кошелька)

## 🛠️ Настройка Кошелька Казино

### Где Взять Адрес Кошелька?

Вам нужен **собственный TON кошелек** для получения депозитов. Вот как его получить:

#### Вариант 1: Создать Новый Кошелек

1. **Скачайте Tonkeeper** (https://tonkeeper.com) или любой другой TON кошелек
2. **Создайте новый кошелек** и сохраните seed-фразу
3. **Скопируйте адрес кошелька** (формат: `EQ...` или `UQ...`)
4. **Конвертируйте в raw формат** используя https://ton-address-converter.com/
   - Вставьте ваш адрес (EQ... или UQ...)
   - Скопируйте **Raw Address** (формат: `0:e430f363...`)

#### Вариант 2: Использовать Существующий

Если у вас уже есть TON кошелек:
1. Откройте ваш кошелек
2. Скопируйте адрес
3. Конвертируйте в raw формат на https://ton-address-converter.com/

### Настройка .env Файла

1. **Откройте файл `.env`** в корне проекта
2. **Замените адрес** на ваш собственный:

```bash
VITE_CASINO_WALLET_ADDRESS=0:ВАШ_АДРЕС_ЗДЕСЬ
```

**Пример:**
```bash
VITE_CASINO_WALLET_ADDRESS=0:e430f363294077ba96e5e01a41d537c93b7c55c4b321f66877bfb36a25c34627
```

3. **Сохраните файл** и перезапустите приложение

## 💰 Как Работает Финансовая Логика

### Балансы

Приложение отслеживает **два баланса**:

1. **Баланс в кошельке (Wallet Balance)** - реальный баланс TON в подключенном кошельке
   - Отображается как "Your wallet ... | X.X TON"
   - Обновляется через TON Center API

2. **Баланс в приложении (App Balance)** - виртуальный баланс для игр
   - Отображается как "Portals wallet balance: X TON"
   - Хранится в localStorage браузера
   - Используется для ставок в играх

### Поток Средств

```
Кошелек Пользователя (TON Blockchain)
         ↓ ДЕПОЗИТ (реальная транзакция)
Кошелек Казино (TON Blockchain)
         ↓ Обновление
Баланс в Приложении (localStorage)
         ↓ ИГРЫ
Выигрыш/Проигрыш (виртуально)
         ↓ ВЫВОД
Кошелек Пользователя (нужна реализация)
```

## 🔄 Полная Интеграция - Что Нужно Доработать

Для **полноценной работы** системы депозитов и выводов нужно:

### 1. Backend Сервис для Выводов

Создать серверный компонент, который:
- Мониторит запросы на вывод от пользователей
- **Автоматически отправляет TON** с кошелька казино на кошельки пользователей
- Использует TON SDK для создания и подписи транзакций
- Хранит приватный ключ кошелька казино в безопасном месте

**Технологии:**
- TON SDK (`@ton/ton`, `@ton/core`)
- Backend на Node.js/Express
- База данных для отслеживания транзакций

### 2. Мониторинг Входящих Депозитов

Система должна:
- **Отслеживать реальные входящие транзакции** на адрес кошелька казино
- Связывать транзакции с пользователями (по адресу отправителя или комментарию)
- Автоматически обновлять баланс в базе данных

**Как это работает:**
```typescript
// Мониторинг входящих транзакций
const client = new TonClient({ endpoint: 'https://toncenter.com/api/v2/jsonRPC' });

// Проверка транзакций каждые 10 секунд
setInterval(async () => {
  const transactions = await client.getTransactions(casinoAddress, { limit: 10 });
  
  for (const tx of transactions) {
    // Проверить если это депозит
    if (tx.in_msg && !tx.out_msg) {
      const sender = tx.in_msg.source;
      const amount = tx.in_msg.value;
      
      // Обновить баланс пользователя в БД
      await updateUserBalance(sender, amount);
    }
  }
}, 10000);
```

### 3. База Данных

Вместо localStorage нужна:
- **PostgreSQL** или другая база данных
- Таблицы: `users`, `transactions`, `game_sessions`
- Отслеживание всех депозитов, выводов и игр

## 🔒 Безопасность

### Критически Важно:

1. **НИКОГДА не храните seed-фразу** кошелька казино в коде или .env файле
2. **Используйте отдельные кошельки:**
   - Hot wallet (горячий) - для повседневных транзакций (небольшие суммы)
   - Cold wallet (холодный) - для хранения основных средств
3. **Мониторьте все транзакции** на предмет подозрительной активности
4. **Используйте rate limiting** для предотвращения спама

### Рекомендации:

- Храните приватные ключи в **encrypted environment variables** или **secret management сервисах** (AWS Secrets Manager, HashiCorp Vault)
- Используйте **multi-sig кошельки** для больших сумм
- Регулярно переводите средства с hot wallet в cold wallet
